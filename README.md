# 🧠 Python for DevOps – AI Edition

A **hands-on Python for DevOps learning repository** designed to help beginners and early DevOps engineers build **strong automation skills** using Python, system scripting, cloud basics, and real DevOps use cases.

This repository follows a **Day-wise structured approach** with practical scripts instead of theory-only content.

---

## 🎯 Who Is This For?

- Aspiring **DevOps Engineers**
- Linux / System Admins moving to DevOps
- Students learning **Python for automation**
- Anyone who wants to use Python in **CI/CD, cloud, and monitoring**

---

## 🧩 What You Will Learn (4-Day Roadmap)

### 📘 Day 01 – Python Fundamentals for DevOps
📂 `Day-01/`

**Focus:** Strong Python basics required for automation

You will learn:
- Python syntax & execution
- Loops and conditions
- Functions and reusable logic
- File handling basics
- Environment variables
- Basic system-level scripting (CPU checks)

📌 Outcome:  
You will be able to write **simple automation scripts** confidently.

---

### 📘 Day 02 – Python Automation & APIs
📂 `Day-02/`

**Focus:** Automating real tasks using Python

You will learn:
- Python project structure
- Using external packages
- Calling APIs with `requests`
- JSON handling
- Writing scripts for real-world automation scenarios

📌 Outcome:  
You will be able to **interact with APIs and automate workflows**.

---

### 📘 Day 03 – AWS Automation with Python
📂 `Day-03/`

**Focus:** Cloud automation using Python

You will learn:
- AWS basics for DevOps
- Using Boto3 with Python
- Automating EC2 & S3 tasks
- Writing cloud automation scripts
- Understanding IAM & permissions (intro)

📌 Outcome:  
You will be able to **automate cloud resources using Python**.

---

### 📘 Day 04 – Capstone Project (DevOps Automation)
📂 `Day-04/`

**Focus:** End-to-end DevOps automation project

You will learn:
- Combining Python + DevOps concepts
- Structuring a real DevOps project
- Writing production-style scripts
- GitHub repo structuring
- Interview-level explanation of your work

📌 Outcome:  
You will have a **portfolio-ready DevOps automation project**.

---

## 🛠 Tech Stack Used

- **Language:** Python 3.x
- **DevOps Concepts:** Automation, Monitoring, CI/CD basics
- **Cloud:** AWS (Boto3 – basic to intermediate)
- **Version Control:** Git & GitHub
